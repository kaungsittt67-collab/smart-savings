2. Saver-group model (unsupervised)

K-Means found 5 groups in 200 customers using income and spending, with no answer column. We looked at the averages and gave each group a name and a savings tip:

Data: Kaggle, Mall Customer Segmentation Data (vjchoudhary7/customer-segmentation-tutorial-in-python).
